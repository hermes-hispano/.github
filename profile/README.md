# Hermes Hispano

**La comunidad en español de Hermes Agent.** Guías claras, habilidades probadas y gente con la que resolver dudas, en tu idioma.

> [!NOTE]
> Comunidad **no oficial**, hecha por usuarios. Hermes Agent es un proyecto de [Nous Research](https://nousresearch.com), que no patrocina ni respalda esta comunidad. La documentación oficial está en [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs).

## ¿Qué es Hermes Agent?

Un agente de inteligencia artificial de código abierto que se instala en tu ordenador o en un servidor. Trabaja por ti con tus archivos, el terminal, la web y apps de mensajería como Telegram, y aprende habilidades nuevas con el uso.

## Por dónde empezar

| | Guía | Para quién |
|---|---|---|
| 1 | Qué es Hermes y si te sirve | Si aún no lo has probado |
| 2 | Instalarlo paso a paso | Linux, macOS y Windows (WSL) |
| 3 | Elegir modelo y proveedor | Cuánto cuesta y qué conviene |
| 4 | Hablar con Hermes desde Telegram | Tu agente en el móvil |
| 5 | Tus primeras habilidades | Instalar, crear y compartir |
| 6 | Tareas programadas | Que trabaje mientras duermes |

*Las guías se están escribiendo. Cada una se publica solo cuando está probada de principio a fin.*

## Cómo participar

- **¿Tienes una duda?** Pregunta en Discussions → *Preguntas y respuestas*.
- **¿Has montado algo útil?** Enséñalo en *Muestra tu montaje*.
- **¿Quieres aportar una guía o una habilidad?** Lee la guía para colaborar. Todo lo que entra está probado, indica la versión de Hermes y no lleva claves ni datos personales.

Nos regimos por un [código de conducta](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). Aquí se viene a aprender y a ayudar: nada de venta ni spam.
